# Proyecto final Git y Github - Talento Tech 
# Crear un repositorio y añadir cambios a través de Git y Github
Autor: Manuel Marchena

# Pasos seguidos

1. Crear el repositorio 
git remote add origin https://github.com/manuelmarchena/git_github_entrega_final.git
git branch -M main
git push -u origin main

2. Verificar creación, estado y rama actual 
git status

3. Iniciar repositorio 
git init
git add .
git commit -m "Initial commit"

4. Crear la rama nueva 
git checkout -b feature/mejora-readme

5. Verificar la creación y ubicación
git status

6. Commit los cambios
git add .
git commit -m "Se agrega descripión al README"
